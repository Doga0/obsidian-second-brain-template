> [!example] Example note — part of the template. Delete all examples with `python "99 System/scripts/vault_tool.py" clean-examples --yes`.

## Essence
A static site generator turns Markdown and templates into plain HTML files at build time, so pages can be served from any file host or CDN without a running server.
