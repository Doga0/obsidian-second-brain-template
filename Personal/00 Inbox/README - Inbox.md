# Inbox

New notes land here (`Ctrl/Cmd+N`). No metadata required.

Once a week: **move** each note (project / research / idea / knowledge / archive), **link** it (to at least one hub or MOC, with a reason) or **delete** it. With AI: `/sb-inbox`. Details: [[Second Brain Guide#Weekly maintenance (15 min)]]
